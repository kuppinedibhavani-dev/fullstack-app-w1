🚀 Full Stack Authentication App
A simple full-stack web application that implements user authentication using JWT (JSON Web Tokens). Users can sign up, log in, and see a personalized welcome message.

📌 Features
📝 User Signup
🔐 User Login
🔑 JWT Authentication
🔒 Password hashing using bcrypt
👋 Dynamic greeting: "Hello, Username"
⚠️ Error handling for invalid login
🛠️ Tech Stack
Frontend
React
HTML, CSS, JavaScript
Backend
Node.js
Express.js
JWT (jsonwebtoken)
bcryptjs
⚙️ Installation & Setup
1️⃣ Clone the repository
git clone https://github.com/kuppinedibhavani-dev/fullstack-app-w1
cd your-repo-name

SETUP BACKEND
cd backend
npm install
node server.js

BacKend will run on:http://localhost:5000

SETUP FRONTEND
cd frontend
npm install
npm start
Frontend will run on :http://localhost:3000

Test Flow
--Go to Signup page
--Create a new account
--Login using same credentials
